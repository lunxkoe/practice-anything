> **정상 동작 확인되면 체크(`[x]`), 비정상이거나 아직 확인 못했으면 빈 칸(`[ ]`)으로 둔다.**

**범례**
- 🤖 = `RestApiQaFlowTest`(자동화 테스트)로 실제 확인됨
- 🔴 = **확인된 버그** — 명세와 다르게 동작함(dev 기준)
- ✅ = 예전에 문제였지만 dev에 이미 수정 병합됨(재확인 완료)
- 🙋 = 자동화 테스트로 커버되지 않음, 수동 확인 필요(또는 별도 자동화 필요)
- 표시 없는 `[ ]` = 이번에 손 못 댐, 자동화 대상이지만 아직 테스트 코드에 없음

## 0. 요약 — 지금 뭐가 됐고 뭐가 안 됐나

### 자동화 테스트 커버리지

`src/test/java/com/sprint/mission/otboo/qa/RestApiQaFlowTest.java` — 실행: `./gradlew test --tests "com.sprint.mission.otboo.qa.RestApiQaFlowTest"`

**커버됨(일부 시나리오)**: 인증, 사용자/관리자, 속성 정의, 옷(구매링크 추출 제외), 추천, 팔로우, 알림 REST, 공통 일부
**전혀 커버 안 됨**: 소셜 로그인(OAuth2), 날씨(외부 API라 스텁 없이는 위험), 피드, 다이렉트 메시지(STOMP), SSE, 배치, 로그아웃

⚠️ **주의**: "커버됨"이라고 해서 그 도메인의 모든 항목이 검증된 게 아니다 — 각 도메인당 핵심 성공/실패 시나리오 몇 개씩만 실제로 코드로 도는 상태고, 아래 체크리스트에서 🤖 표시 안 된 항목은 같은 도메인이어도 아직 미확인이다. **"의상 쪽 중복 빼고 다 됐다"는 잘못된 이해** — 정확히는 위 "커버됨" 목록 안에서도 일부 시나리오만 확인된 상태다.
